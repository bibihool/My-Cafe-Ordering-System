## The Cafe Ordering System 
is a console-based application developed using C++ and is aimed at modeling the basic working pattern of a small-scale cafe setting. The application allows basic operations like viewing menus, placing orders, calculating bills, processing discounts, and printing bills. The application is a part of the TCP6114 computer programming subject and is developed as an application of the basic concepts learned throughout the trimester. 

 

“The previous version of the Café Ordering System in the assignment was developed by using procedural programming methodologies, where program code was interwoven with its data, including the café's menu items.” This system was enough, but it lacked scalability, flexibility, and maintainability. It was necessary to modify the code itself in case “a new item was added or a current one changed price.” It is not an appropriate method in real-world projects. 

 

In this regard, the system was redesigned using the principles of Object-Oriented Programming and file handling techniques. In it, OOP allows the program to be divided into actual entities that are to be dealt with, such as menu items and customers' orders, encapsulated within well-defined classes. This improves code readability, promotes reuse, and simplifies future enhancements. The responsibilities are clearly divided among classes, reducing redundancy and enhancing logical clarity. 

 

Additionally, it incorporates file handling to allow data persistence. The data about the menu is stored in a CSV external file so administrators can edit menu items without having to change the code of the program. The customer transactions that have been completed are recorded as a receipt record in a text file so that order history can persist after the execution of programs. This is basically similar to how real operational systems act, where data persistence is key to their success. 

 

Overall, the enhanced Cafe Ordering System is a well-structured, modular, and realistic software solution. It incorporates core C++ concepts such as classes, vectors, file input/output streams, control structures, and input validation. The redesigned system addresses the academic requirements of the project but also shapes industry-aligned programming practices suited to real-world problem-solving.
